Phone use
- Open the URL in Safari or Chrome.
- Use the browser Share menu and choose “Add to Home Screen” where available.
- The app includes a Share button that uses the phone's native share sheet when supported.

Important source note
The identification content is grounded in the supplied “BI306 All-Season Tree ID.pdf.” The key is an educational aid, not a comprehensive field guide. Where the supplied guide does not support a confident distinction, the app says so rather than adding outside diagnostic traits.
